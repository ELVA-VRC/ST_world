긴 글 스크롤 테스트

이 글은 스크롤 길이 자동 계산을 확인하기 위해 일부러 길게 만든 샘플이다.
본문 창을 열었을 때 처음에는 맨 위에서 시작해야 하고, 아래로 스크롤하면 끝까지 자연스럽게 내려가야 한다.

첫 번째 확인 포인트는 글 끝 이후로 너무 긴 빈 공간이 생기지 않는지다.
짧은 글에서는 content 높이가 viewport 높이 이상으로만 잡히고, 긴 글에서는 줄 수에 맞춰 더 길어진다.

두 번째 확인 포인트는 마스킹이다.
본문이 창 밖으로 올라가거나 내려갈 때, 창 영역 바깥에서는 텍스트가 보이지 않아야 한다.
이 부분은 ScrollRect의 viewport에 RectMask2D가 붙어 있어야 정상적으로 작동한다.

세 번째 확인 포인트는 언어 전환이다.
LANG 버튼으로 KO와 JA를 오가면 같은 슬롯의 다른 언어 파일을 다시 받아와서 표시해야 한다.
이때 스크롤 길이도 다시 계산되어야 한다.

네 번째 확인 포인트는 폰트 크기와 행간이다.
Unity 인스펙터에서 contentFontSize나 contentLineSpacing을 바꾸면 글의 실제 TMP 설정과 Udon의 높이 추정값이 함께 맞아야 한다.
값을 크게 올리면 한 화면에 들어가는 줄 수가 줄어들고, 스크롤 길이는 더 길어지는 것이 자연스럽다.

마지막 확인 포인트는 새 글 업데이트 흐름이다.
이 파일은 GitHub Pages의 docs/entries/005.ko.txt에 있으므로, 나중에 브라우저에서 파일을 수정하고 커밋하면 월드 재업로드 없이 내용이 바뀐다.
VRChat 안에서는 Reload 버튼을 누르거나 같은 항목을 다시 열어 새 내용을 받아오면 된다.
