최종 장문 샘플

이 글은 25번째 샘플이며, 가장 마지막 항목이자 장문 테스트용 글이다.
목록의 다음/이전 버튼, 마지막 페이지의 항목 수, 본문 다운로드, 스크롤 마스킹을 한 번에 확인할 수 있다.

첫 번째로 확인할 것은 마지막 페이지 표시다.
세 번째 페이지에는 20번부터 24번까지 다섯 개의 항목만 있어야 한다.
나머지 버튼은 비활성화되거나 보이지 않아야 하며, 페이지 표시는 3 / 3으로 나와야 한다.

두 번째로 확인할 것은 본문 다운로드다.
이 항목을 누르면 docs/entries/024.ko.txt 파일만 받아온다.
앞의 24개 본문을 미리 받지 않으므로, 실제 일기가 많아져도 초기 로딩이 크게 늘어나지 않는다.

세 번째로 확인할 것은 스크롤 끝부분이다.
글을 끝까지 내렸을 때 마지막 줄이 보이고, 그 아래에 약간의 여백만 남는지 확인한다.
너무 긴 빈 공간이 남으면 contentHeightPadding 또는 높이 추정식을 조정해야 한다.

네 번째로 확인할 것은 언어 전환 후 재계산이다.
LANG 버튼을 눌러 일본어로 바꾸면 docs/entries/024.ja.txt가 다시 로드되고, 본문 길이에 맞춰 스크롤 높이가 다시 계산되어야 한다.
한국어와 일본어는 글자 폭과 줄바꿈 느낌이 다르기 때문에 완전히 같은 높이가 나오지 않아도 된다.
다만 글 끝까지 자연스럽게 내려갈 수 있어야 한다.

마지막으로, 이 파일은 앞으로 네가 직접 수정해도 된다.
GitHub 웹사이트에서 파일을 열고 Edit 버튼을 누른 뒤 내용을 바꾸고 Commit changes를 누르면 GitHub Pages가 다시 배포한다.
월드는 다시 빌드하지 않아도 되고, 반영 후 월드 안에서 Reload 또는 항목 다시 열기로 새 내용을 확인하면 된다.
