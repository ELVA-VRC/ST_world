세 번째 페이지 장문 테스트

세 번째 페이지에서도 긴 글이 정상적으로 열리는지 확인하기 위한 샘플이다.
페이지가 바뀐 뒤 슬롯 번호가 20번 이상으로 넘어가도 URL은 docs/entries/020.ko.txt처럼 그대로 이어진다.

이 구조는 나중에 일기가 많아졌을 때도 단순하게 유지하기 좋다.
월드 안에는 글 전체가 들어가지 않고, GitHub Pages에는 파일만 추가하면 된다.
목록 페이지는 10개 단위로 나누고, 실제 본문은 사용자가 클릭한 항목만 받아온다.

스크롤 계산은 월드 빌드 시점이 아니라 글을 받아온 뒤 UdonSharp에서 실행된다.
따라서 이 파일을 나중에 더 길게 바꾸거나 짧게 줄여도, 월드를 다시 업로드하지 않고 테스트할 수 있다.
다만 GitHub Pages 반영에는 약간의 시간이 걸릴 수 있고, VRChat 쪽에서는 Reload나 다시 열기가 필요할 수 있다.

이 문단은 길이 확인을 위해 추가로 넣은 부분이다.
한 줄이 너무 길게 이어지는 경우와 문단이 여러 개로 나뉘는 경우를 모두 확인해야 한다.
텍스트가 viewport 밖으로 나가면 RectMask2D가 잘라줘야 하고, 끝까지 스크롤했을 때 마지막 줄이 창 하단에 너무 붙지 않도록 padding이 들어간다.
